# PR #476 (CTO review 27 Oct 2026): admits a Colab take only when spent-or-reserved + its max_cu

# process group and stops the VM at max_cu (30 s polls). If every Contabo process dies mid-take,
# the VM's own watchdog releases it 15 min after the last heartbeat: about 2.3 CU more on a G4
# (8.9 CU/h). Studio and Openjutsu takes run on G4 only; no other GPU's rate is measured.

# during `colab new` can leave an orphan VM that no guard stops.
tools/colab_batch.py --max-credits
