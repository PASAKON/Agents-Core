# 3.5 ตารางตรวจสอบเสียงด้วย AudioSet (PANNs CNN14) — HEARD Validation

เอกสารนี้เป็นส่วนต่อขยาย (Section 3.5) สำหรับประกอบ `BREAKDOWN.md` ของหนังสั้น "Listen to Meh" (Purga Studio, 5:30 / 330 วินาที) โดยนำข้อสันนิษฐานเดิมในหัวข้อ 3 (ซึ่งเดิมวิเคราะห์จากกราฟ LUFS และสเปกโตรแกรมเท่านั้น จึงจัดเป็น INFERRED) มาตรวจสอบเทียบกับผลการจำแนกประเภทเสียงจริงระดับวินาทีต่อวินาที (Top-5 AudioSet labels พร้อมค่าคะแนนความเชื่อมั่น 0.00–1.00) จากโมเดล **PANNs CNN14** (`tags_1s.csv` และ `tags_10s_summary.txt` จัดทำโดย CMO)

---

## 1. นิยามสถานะการตรวจสอบ (Status Definition)

- **HEARD-confirmed**: ผลลัพธ์จาก AudioSet ยืนยันตรงกับข้อสันนิษฐานเดิม (มีเลเบลเสียงตรงกับที่คาดการณ์ไว้ เช่น เสียงลมหายใจ, ฟอลีย์แกะ/สัตว์, เสียงฝน/พายุ, เสียงดนตรีไคลแมกซ์)
- **HEARD-different**: เสียงจริงที่โมเดลตรวจจับได้แตกต่างจากที่คาดการณ์ไว้ใน BREAKDOWN เดิมอย่างมีนัยสำคัญ หรือมีการค้นพบเลเบลเสียงหลักใหม่ที่พลิกความเข้าใจเดิม
- **still unknown**: ข้อมูลเลเบลยังไม่ชี้ชัด 100% เนื่องจากเป็นเสียงผสมผสานหลายชั้น (Layered audio) หรืออยู่นอกชุดคำศัพท์หลักของ AudioSet 527 คลาส

## 3. สรุปข้อค้นพบสำคัญที่เปลี่ยนความเข้าใจด้านเสียง (Core Audio Insights)

1. **ดนตรีแท้จริงมาช้ากว่าที่ตาเห็น (Score Delayed until 73%)**:
   - ใน BREAKDOWN เดิมระบุว่าดนตรีเข้าที่ 2:22 (43% ของเรื่อง) แต่ผล AudioSet ชี้ชัดว่า **2:22 คือเสียงไซเรน/ฮอร์นเตือนภัย (`Civil defense siren`)** ร่วมกับเสียงพายุ
   - **ดนตรีสกอร์หลัก (Symphonic Score) เข้าจริงที่ 4:00 (วินาทีที่ 241 = 73% ของความยาวเรื่อง!)** หนังกล้าใช้เสียงฟอลีย์และธรรมชาติแบกอารมณ์ไว้ถึงเกือบสามในสี่ของเรื่อง แล้วจึงปลดปล่อยพลังดนตรีทั้งหมดใน 1 นาทีครึ่งสุดท้าย
2. **ธรรมชาติคือดนตรีในช่วงองก์ 2 (Nature as Score in Act 2)**:
   - เสียงฟ้าร้อง (`Thunder` 0.77) เริ่มปะทุตรงกับวินาทีที่ 2:31 (ช็อต 32 แสงแดงขอบฟ้า) พอดีเป๊ะ
