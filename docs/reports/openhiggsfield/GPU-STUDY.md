# Openjutsu: ใช้ GPU นานแค่ไหน แพงแค่ไหน (PH#81f, 30 ต.ค. 2026, ตอบ Q-20261029-0520-783a)

**สรุป**: บน H100 คลิป 6 วิ ใช้ราว 2-4 นาที ค่า GPU ราว $0.1-0.3 ต่อคลิป. แต่ทุกครั้งที่เปิดเครื่องใหม่ต้องโหลดโมเดลราว 55 GB
(15-25 นาที). Colab ฟรี (T4) รันไม่ได้ เพราะ RAM ไม่พอ ต้องใช้ Colab Pro แบบ A100 high-RAM.
ไม่มีการรันจริง ทุกตัวเลขยกเว้นที่เขียนว่า verified เป็นการประมาณ.

## 1. เวลา + ค่าใช้จ่ายต่อคลิป

|---|---|---|---|---|

| RTX 4080 SUPER 16 GB (winbox) | ~4-8 นาที, $0 | ~8-16 นาที | ~11-21 นาที | VRAM ได้ RAM ยังไม่ได้เช็ก |
| Colab T4 ฟรี (RAM 12.7 GB) | รันไม่ได้ | รันไม่ได้ | รันไม่ได้ | ไม่ได้: ตัวโมเดลหลัก 21 GB |

ที่มาของตัวเลขประมาณ: 736p มีพิกเซลมากกว่า 480p 2.35 เท่า (นับเวลาเป็น 2 เท่า). H100 อิงเวลาที่เราวัดเอง: H3 720p 15 วิ ใช้ 444-572 วิ
(research 2026-09-28, verified), ตัดตามความยาวคลิป. 4080 SUPER นับว่าเร็วกว่า 4060 Ti 1.5-1.8 เท่า. A100 นับว่าช้ากว่า H100 1.5-2 เท่า.
ยังไม่รวม: เปิดเครื่อง RunPod ราว 7 นาที ($0.38, วัดแล้ว) + โหลดโมเดลครั้งแรก.

## 2. Colab
- ขนาดโมเดลที่ต้องโหลด: H3 ref2va pruned int8 21.0 GB, VAE 2.8 + 0.6 GB (**verified**, Comfy-Org/MiniMax-H3 บน HF);
  text encoder 32B int4 ~17 GB, Qwen3-VL 8B int8 ~9 GB, SAM 3.1 + LoRA ~4 GB (assumed). รวมราว **55 GB**.
- ติดตั้ง: ComfyUI + custom node 12 ตัว + comfy-api-proxy (Python) + Node 22 + โหลดโมเดล ≈ 30-40 นาทีต่อ session (Colab ล้างเครื่องทุกครั้ง).
  สคริปต์เปิดเครื่อง `start_openjutsu.bat` ใช้ได้แค่ Windows; บน Colab ต้องทำตามขั้นตอนมือใน README และเปิดหน้าเว็บผ่าน tunnel.
- ค่า Colab: Pro $9.99/100 CU; A100 ประมาณ 11-13 CU/ชม. (assumed) → ราว $1.2/ชม. หนึ่ง session ทดสอบ (ติดตั้ง + 1 คลิป) ≈ 1 ชม. ≈ $1.2 ของ CU.
- Colab ถูกสงวนไว้ให้ CEO ตั้งแต่ 27 ต.ค. ทีมจึงไม่เปิดเอง.

## 3. เทสต์จริงที่ถูกที่สุด (1 คลิป)
1. Colab A100 high-RAM, ติดตั้ง ComfyUI + node ตาม README, โหลดโมเดลจาก HF (~20 นาที).
2. รัน Simple motion transfer: วิดีโอเรา 6 วิ 480p + รูปตัวละคร 1 รูป (ไม่ใช่รูปคนจริง).
3. จดเวลาแต่ละขั้น (SAM, Qwen, H3) แล้วดูผลด้วยตา. รวม ~1 ชม., ~$1.2 ของ CU ถ้ามี Colab Pro อยู่แล้ว.
ทางเลือก: RunPod H100 ราว 45 นาที ≈ $2.5 (รวมเปิดเครื่อง + โหลด) ต้องขออนุมัติเงินก่อน.
