## กฎที่ใช้กับทุกเพลต

- เพลตตัวละคร: พื้นหลังเทากลางเรียบ แสงนุ่มเท่ากันทั้งหน้า ไม่มีแสงอารมณ์ ไม่มีฉาก (แสงและสีของหนังมาจากบล็อก Colour grade ใน prompt ไม่ใช่จากเพลต)
- `<ตัว>__face` ทำก่อน ทุก state ของตัวนั้นต่อในแชตเดียวกัน (runner `continue`) แชตใหม่ = คนใหม่
- Prop และ location ที่อยู่ในฉากเดียวกันต้อง crop/ต่อในแชตของฉากนั้น
- ฉากต่างเวลา = เพลตคนละใบ ทำต่อในแชตเดิม (กฎ 2: คำว่า "night" ในข้อความไม่ชนะเพลตฉากกลางวัน)
- สีหน้าไม่ใช่ state (อยู่ใน prompt ของแต่ละช็อต) สภาพร่างกายที่ติดตัวข้ามช็อตคือ state
- ผู้ใหญ่ 18+ ทุกคน ไม่มีหน้าแดงหรือหูแดง ไม่มีตัวหนังสือ โลโก้ ตราในเพลต
- **ข้อจำกัด:** กฎ 4 และ 8 วัดผลบน Flow (แนบ 3 chip ต่อช็อต) H3 รับ ref ได้มากกว่า แต่ยังไม่เคยวัดว่าเพลตเทากลางดีกว่าเพลตมีแสงบน H3 [A] คลิปแรกที่ยิงคือการวัด

## เอกลักษณ์ (identity) ของแต่ละตัว: ต้องจำได้แม้เห็นตัวเล็ก 1/5 ของเฟรมและจากเงา

| ตัว | เอกลักษณ์ที่ล็อก | ทำไมเห็นชัดในระยะไกล |
|---|---|---|
| **ออร์เฟียส** (late 20s) | ผมหยักศกยาวประบ่า มงกุฎใบมะกอก หนวดสั้นเข้ม เสื้อคลุมขนสัตว์สีเข้มพาดไหล่ซ้ายมีแถบขอบสีอำพัน-เหลืองออกร์ เสื้อทูนิกสีขาวนวล เข็มขัดเชือก | ทูนิกอ่อนตัดกับเสื้อคลุมเข้ม + แถบอำพันตรงกับสีพิณ |
| **กษัตริย์แห่งยมโลก** (40s) | สูงที่สุดในเรื่อง ผิวเทาเถ้า มงกุฎหินดำ ปกเสื้อสูงแข็ง แหวนหินดำหนักที่นิ้วชี้ขวา | มงกุฎหินดำทรงแหลมชัดกว่าเงาใคร |
| **ราชินีแห่งยมโลก** (30s) | ผิวเทาเถ้า ผมดำตรงยาว มงกุฎหินดำ ปกเสื้อสูง ลายปักลูกทับทิมด้ายทองคล้ำที่ปก | ผมดำยาวคู่กับมงกุฎ ตัดกับกษัตริย์ผมสั้น |
| **ยูริไดซี** | เงาเท่านั้น: ชุดลินินยาวสีซีดกับผ้าคลุมศีรษะยาวสีซีด ไม่มีหน้า | ชุดซีดเป็นสีเดียวในทุ่งมืด |
| **ผู้เล่า** | มือแก่เท่านั้น: ปลายนิ้วเปื้อนหมึก แหวนเหล็กเรียบวงเดียวที่นิ้วนางขวา | แหวน + หมึกเห็นในช็อตมือติดกล้อง |
| **สัตว์สามตัว** | กวางสีน้ำตาลแดงไม่มีเขา หมาป่าเทาอกขาว จิ้งจอกสีสนิมปลายหางขาว | สามสีสามทรงต่างกันชัด |
| **พิณ** | เนื้อไม้สีอำพันเข้ม ตัวโค้งลึก แขนโค้งสองข้างปลายม้วน คานตรง เจ็ดสาย | สีอำพันเดียวกับแถบเสื้อคลุม |
