# Feed Them, Feed Me — Plate Log

Project: https://higgsfield.ai/generate/@ilag-studio/ai-film-festival-2
Settings for all plates: GPT Image 2, Medium, 1K. Character sheets use aspect 21:9; everything
else Auto. 2 credits per plate.

> **Mid-run CEO amendment** (arrived after Milo and Nadia single-pose plates were already
> generated): character plates must be **reference sheets** (multiple angles/expressions in one
> wide image), not single portraits. A first spec (8-panel grid) was superseded seconds later by
> a second, concrete spec modeled on the Do Not Disturb project's reference-sheet format: one
> wide ~2.4:1 image, 4 panels — front (DRY), close-up portrait (WET), profile (DRY), back (WET) —
> each with a different expression, one panel carrying the character's signature
> relationship-to-camera pose. The single-pose plates for Milo and Nadia were kept per the CEO's
> instruction ("if you already generated a single-pose character plate, keep it, generate the
> sheet as well, and report both ids").
