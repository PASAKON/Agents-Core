# 6 รูปแบบโพสต์ — พร้อมของจริงที่เรามีอยู่แล้ว

### 1. 🎬 ฉากเดียว เบื้องหลังเต็ม ← **รูปแบบที่ไม่มีใครลอกเราได้**
คลิปจากหนัง 10-20 วินาที + เล่าว่าฉากนั้น**จริง ๆ แล้วใช้อะไรไปบ้าง**

> *"ฉากนี้ 8 วินาที ยิงไป 6 เทค เทคที่ผ่านไม่ใช่เทคที่สวยที่สุด แต่เป็นเทคเดียวที่หน้าตัวละครไม่เปลี่ยน"*

**ลอกไม่ได้เพราะเขาไม่มีหนัง** — ของเรามี 781 generations กับ 9.1 GB เป็นหลักฐาน

### 2. 📊 ตัวเลขที่วัดเอง
ตาราง 3 โมเดล prompt เดียวกัน Element เดียวกัน: **2.5 = 98 เครดิต/11-19 นาที · 2.0 Fast = 53/4.5 นาที · 2.0 Mini = 38/3.5 นาที**

คนไทยสายนี้แชร์ตารางแบบนี้ต่อแน่นอน เพราะไม่มีใครวัดเอง

### 3. 💸 ความผิดพลาดที่แพง ← **ตัวที่จะไปไกลที่สุด**
- ปุ่มที่กดแล้วเสีย **130 เครดิตโดยไม่ถาม**
- reference plate **ตายย้อนหลัง** — ผ่านตอน 10:41 ตายตอน 11:47 ทั้งที่ไม่ได้แตะ
- คลิปโดนปฏิเสธ 2 รอบเพราะ **ชื่อตัวละคร** ไม่ใช่รูป

**ไม่มีใครโพสต์ความผิดพลาดของตัวเอง** และนั่นคือเหตุผลที่มันจะถูกแชร์

### 4. 🎞️ คลิปสั้นล้วน แบบแมวอ้วน
ตัดจากหนัง + แคปชั่นที่เป็น**เรื่อง** ไม่ใช่เครื่องมือ

> ❌ *"คลิปนี้ทำด้วย Seedance 2.5"*
> ✅ *"เขากดกริ่งห้อง 302 ทุกคืน คืนนี้มีคนเปิด"*

### 5. 🔄 พรอมต์ที่พัง vs พรอมต์ที่ผ่าน
เรามีเลดเจอร์ A/B **29 เคส** ที่บันทึกไว้ว่าอะไรพัง แก้ยังไง แล้วทำไมถึงหาย

> *"สั่ง 'ห้ามวิ่ง' → เขาวิ่ง · ที่แก้ได้คือใส่ตัวเลขความเร็ว + 'เท้าหนึ่งข้างติดพื้นเสมอ'"*

**เป็นคอนเทนต์ที่มีแต่คนทำจริงเท่านั้นที่มี**

### 6. 💬 ตอบคอมเมนต์เป็นโพสต์
คำถามดี ๆ ในคอมเมนต์ = โพสต์หน้า ตอบยาว ให้เครดิตคนถาม
