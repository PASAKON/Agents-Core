# บทพูดทั้งหมด — ก๊อปไปใช้ได้เลย

CTO · 2026-09-15 · แก้ให้เป็นภาษาคุณได้ แต่**อย่าทำให้ยาวขึ้น**

---

## หลักการ 4 ข้อ ที่ทำให้ข้อความพวกนี้ได้ผล

1. **สั้น** — เจ้าของร้านอ่านข้อความยาวไม่จบ
2. **ไม่ขาย ถามความเห็น** — คนไทยปิดประตูใส่คนขาย แต่เปิดให้คนขอคำแนะนำ
3. **ทำให้ปฏิเสธง่าย** — ยิ่งกดดันน้อย ยิ่งได้คำตอบเยอะ
4. **อย่าเพิ่งพูดราคาในข้อความแรก** — ให้เขาเห็นของก่อน

---

# 📩 ข้อความแรก — เลือกตามความสนิท

## แบบ A — สนิทมาก (เพื่อน พี่น้อง คนที่ทักได้ตลอด)

```
พี่ ผมทำระบบ AI ตอบแชทลูกค้าให้ร้านตัวเองมาพักนึงแล้ว
ตอนนี้ไม่ต้องจ้างแอดมินเลย มันตอบแทนได้หมด

อยากลองเอาไปติดให้ร้านพี่ดูฟรี ๆ
คืออยากรู้ว่ามันใช้กับร้านคนอื่นได้จริงไหม

ถ้าใช้แล้วไม่เวิร์คก็ด่าได้เลยนะ ผมจะได้เอาไปแก้
```

**ทำไมได้ผล:** ไม่ได้ขอให้เขาซื้อ ขอให้เขาช่วยทดสอบ — คนสนิทปฏิเสธคำขอแบบนี้ยาก และไม่รู้สึกว่าโดนขาย

---

## แบบ B — รู้จักผ่าน ๆ (เคยคุย เคยเจอ อยู่ในกลุ่มเดียวกัน)

```
สวัสดีครับพี่[ชื่อ] ผมกอล์ฟนะครับ [ที่เรารู้จักกัน เช่น "เคยเจอกันที่..."]

พอดีผมทำระบบ AI ตอบแชทลูกค้าให้ร้านตัวเองอยู่
เมื่อก่อนจ้างแอดมินเดือนละ 8,000 ตอนนี้ไม่ต้องจ้างแล้ว

เห็นร้านพี่ลูกค้าทักเยอะ เลยนึกถึง
สนใจลองดูไหมครับ ผมติดตั้งให้ฟรี ลองใช้ก่อนได้เลย

ไม่ต้องรีบตัดสินใจครับ ไม่สนใจก็ไม่เป็นไรเลยนะครับ
```

---

## แบบ C — เคยเป็นลูกค้าเรา / เคยซื้อของเรา

```
พี่[ชื่อ] สบายดีไหมครับ

ผมทำระบบ AI ตอบแชทให้ร้านตัวเองไว้ ใช้มาพักนึงแล้วดีเกินคาด
เมื่อก่อนจ้างแอดมิน 8,000 ตอนนี้ปล่อยให้มันตอบเองทั้งหมด

กำลังหาร้าน 5 ร้านแรกมาลองใช้ฟรี นึกถึงพี่เป็นคนแรก ๆ
สนใจไหมครับ ผมติดตั้งให้เอง ไม่มีค่าใช้จ่ายช่วงทดลอง
```

---

# 🎬 ข้อความที่ 2 — ตอนเขาสนใจ ให้ยิงอันนี้ทันที

**นี่คือข้อความที่ปิดการขายจริง ไม่ใช่ข้อความแรก**

```
เดี๋ยวพี่ลองทักเข้าร้านผมดูก่อนเลยครับ
[ลิงก์ไลน์ร้านคุณ]

ถามอะไรก็ได้เหมือนลูกค้าจริง ๆ ถามราคา ถามของ ถามส่งกี่วัน
จะได้เห็นว่ามันตอบยังไง

ลองเล่นได้เต็มที่เลยครับ ยังไม่ต้องตัดสินใจอะไร
```

> **ให้เขาลองเอง คือการขายทั้งหมด** — อย่าอธิบายว่ามันทำงานยังไง อธิบายมากยิ่งขายยาก

---

# 💬 เขาถามอะไรมา ตอบยังไง

## ❓ "ราคาเท่าไหร่"

```
ปกติ 2,900/เดือนครับ

แต่ 5 ร้านแรกที่มาลองใช้ ผมให้ 1,900 ล็อกราคาไว้ 1 ปีเลย
ติดตั้งฟรีด้วย (ปกติคิด 10,000)

แลกกับขอเอาไปเป็นตัวอย่างให้คนอื่นดูได้ครับ
```

**จุดยึด:** ถ้าเขาลังเล ให้เทียบกับเงินเดือนแอดมินเสมอ
> *"เทียบกับจ้างคน 8,000 แล้วยังลา ยังหยุด อันนี้ 1,900 ทำงานทุกวันไม่มีวันหยุดครับ"*

---

## ❓ "AI จะตอบมั่วไหม" ← **คำถามที่เขากลัวที่สุด ตอบให้ดี**

```
ไม่ครับ มันตอบได้เฉพาะเรื่องที่เราสอนมันไว้เท่านั้น

อะไรที่ไม่รู้ มันจะไม่เดา แต่จะส่งต่อให้พี่ตอบเอง
ราคา โปรโมชั่น เงื่อนไข เราใส่ให้หมดตอนติดตั้ง

ช่วงแรกพี่ดูได้ทุกข้อความว่ามันตอบอะไรไปบ้าง
ถ้าตอบไม่ถูกใจตรงไหน บอกผม ผมแก้ให้ทันที
```

**นี่คือความกลัวจริงของเขา ไม่ใช่เรื่องราคา** — ตอบข้อนี้ได้ ที่เหลือง่ายหมด

---

## ❓ "ลูกค้าจะรู้ไหมว่าคุยกับบอท"

```
ส่วนใหญ่ไม่รู้ครับ เพราะมันตอบเป็นภาษาคนปกติ

แต่ถ้าพี่อยากให้บอกตรง ๆ ว่าเป็นระบบอัตโนมัติก็ทำได้
บางร้านชอบแบบนั้นมากกว่า แล้วแต่พี่เลยครับ
```

---

## ❓ "ต้องทำอะไรบ้าง ยุ่งยากไหม"

```
พี่ไม่ต้องทำอะไรเลยครับ ผมติดตั้งให้ทั้งหมด

พี่แค่บอกผมว่า ขายอะไร ราคาเท่าไหร่ ส่งยังไง
คำถามที่ลูกค้าถามบ่อย ๆ มีอะไรบ้าง

ที่เหลือผมจัดการ เสร็จแล้วพี่ใช้ได้เลย
```

---

## ❓ "ร้านผมเล็ก ไม่คุ้มหรอก"

```
ยิ่งร้านเล็กยิ่งคุ้มครับ เพราะจ้างคนไม่ไหวอยู่แล้ว

ที่ผ่านมาพี่ตอบเองใช่ไหมครับ ตอนกินข้าว ตอนนอน
ตัวนี้มันตอบให้ตอนที่พี่ไม่ว่าง ลูกค้าไม่ต้องรอ
```

---

## ❓ "ขอคิดดูก่อน" ← **ห้ามตื๊อ**

```
ได้เลยครับ ไม่ต้องรีบ

ผมส่งลิงก์ร้านผมไว้ให้ก่อน พี่ลองเล่นดูตอนไหนก็ได้
[ลิงก์]

อีกสักอาทิตย์ผมทักมาถามอีกทีนะครับ
ถ้าไม่สนใจก็บอกได้เลย ไม่ต้องเกรงใจครับ
```

**แล้วทักจริงในอีก 7 วัน** — จดวันไว้ในตาราง
**"ขอคิดดูก่อน" ส่วนใหญ่แปลว่า "ยังไม่เข้าใจ"** ไม่ได้แปลว่าไม่เอา

---

## ❓ เงียบหายไปเลย

**ทัก 1 ครั้ง หลัง 7 วัน แค่ครั้งเดียว**

```
พี่ครับ ไม่ทราบว่ายังสนใจอยู่ไหมครับ
ถ้าตอนนี้ยังไม่สะดวกก็ไม่เป็นไรนะครับ
ผมจะได้ไม่รบกวนอีก
```

**ถ้ายังเงียบ = จบ ไปหาคนต่อไป** อย่าตามเกิน 2 ครั้ง ไม่คุ้มและเสียความสัมพันธ์

# 💰 ข้อความเรื่องเงิน

## ตอนปิดดีล

```
โอเคครับพี่ เดี๋ยวผมติดตั้งให้ภายใน [วัน]

ช่วงทดลอง 14 วันแรกฟรีครับ ยังไม่ต้องจ่ายอะไร
ถ้าใช้แล้วโอเค ค่อยเริ่มคิด 1,900/เดือนตั้งแต่เดือนหน้า
ถ้าไม่โอเค บอกเลิกได้เลย ไม่มีผูกมัดครับ
```

## ส่งบิลเดือนแรก

```
พี่[ชื่อ] ครบกำหนดค่าบริการ Chatudo เดือน[เดือน] แล้วครับ
1,900 บาท

โอนตาม QR นี้ได้เลยครับ
[QR PromptPay]

เดือนที่ผ่านมาบอทตอบไป [จำนวน] ข้อความครับ
```

> **ใส่ตัวเลขทุกครั้งที่ส่งบิล** — ให้เขาเห็นว่าจ่ายไปแล้วได้อะไร นี่คือสิ่งที่กันการเลิกใช้ได้ดีที่สุด

## เสนอรายปี (ยิงตอนเดือนที่ 2)

```
พี่ ถ้าจ่ายรายปีผมลดให้ 2 เดือนครับ
จ่าย 10 เดือน ใช้ได้ 12 เดือน = 19,000

ไม่ต้องมาโอนทุกเดือนด้วย สะดวกกว่าครับ
```

## ⛔ คำที่ห้ามใช้เด็ดขาด

| ห้าม | ใช้แทน |
|---|---|
| "AI", "แชทบอท", "ระบบอัตโนมัติ" ในประโยคแรก | **"ระบบตอบแชทแทนแอดมิน"** |
| "โซลูชั่น", "แพลตฟอร์ม", "ดิจิทัลทรานส์ฟอร์ม" | พูดเหมือนคุยกับเพื่อน |
| "สนใจไหมครับ" ซ้ำ ๆ | ถามคำถามที่เขาตอบได้ |

**คำว่า "AI" ทำให้คนไทยรู้สึกว่าแพงและยาก** — พูดว่า "ตอบแชทแทนแอดมิน" เขาเข้าใจทันทีและรู้สึกว่าเป็นของที่ซื้อได้
