# เช็กลิสต์ติดตั้ง + ตารางจับเวลา

**จับเวลาทุกขั้น ตั้งแต่รายแรก** — นี่คือข้อมูลที่แพงที่สุดใน 30 วันแรก
มันจะบอกเองว่าต้องทำอะไรให้อัตโนมัติก่อน โดยที่คุณไม่ต้องเดา

## ก่อนติดตั้ง — ขอข้อมูลจากร้าน (ส่งเป็นข้อความเดียว)

```
พี่ส่งข้อมูลพวกนี้มาให้ผมหน่อยนะครับ เท่าที่มี ไม่ต้องครบก็ได้

1. ขายอะไรบ้าง ราคาเท่าไหร่
2. ส่งของยังไง กี่วันถึง ค่าส่งเท่าไหร่
3. โอนเงินยังไง บัญชีอะไร
4. คำถามที่ลูกค้าถามบ่อยที่สุด 5 ข้อ
5. เรื่องไหนที่ห้ามให้ระบบตอบเอง ต้องส่งให้พี่ตอบ
```

## หลังติดตั้ง

- [ ] วันที่ 1-7 ทักถามทุกวัน "มีตรงไหนตอบแปลก ๆ ไหมครับ"
- [ ] วันที่ 7 เก็บตัวเลข: ตอบไปกี่ข้อความ ส่งต่อให้คนกี่ครั้ง
- [ ] วันที่ 14 ถามว่าจะใช้ต่อไหม → ถ้าใช่ เริ่มคิดเงินเดือนหน้า
- [ ] ขออนุญาตถ่ายคลิป/เอาชื่อไปเป็นตัวอย่าง
