# 2. คำแนะนำเรื่อง Automation — **ตอบตรง ๆ: ใช้ API สำหรับเพจ อย่าเขียนสคริปต์กดจอ**

## ข้อเท็จจริงที่ตัดสินทุกอย่าง

**Meta API โพสต์ได้เฉพาะ "เพจ" เท่านั้น**

| เป้าหมาย | API ทำได้ไหม |
|---|---|
| โพสต์ลงเพจที่เราดูแล | ✅ ได้ |
| **โพสต์ลงโปรไฟล์ส่วนตัว** | ❌ **Meta ปิดไปแล้ว** |
| **โพสต์ลงกลุ่ม** | ❌ แทบทั้งหมดปิดตั้งแต่ 2024 |
| ทัก DM หาคนที่ไม่เคยทักเรา | ❌ |

**แผนโปรโมทของเราพึ่งกลุ่มกับโปรไฟล์ส่วนตัวเป็นหลัก — ซึ่งเป็นสิ่งที่ API ทำไม่ได้ทั้งหมด**

## แล้วสคริปต์กดจอล่ะ ทำได้ทุกอย่างนี่

ทำได้จริง **แต่ผมไม่แนะนำ** ด้วย 3 เหตุผล

1. **ต้องใช้จอ winbox** → ต้องยืม lease ทุกครั้ง → แย่งเวลากับ Cookie Run ทุกวัน
2. **FB เปลี่ยน UI เมื่อไหร่ก็พัง** — เราเจอมาแล้ววันนี้ ปุ่มสร้างเพจย้ายที่จน URL เดิมใช้ไม่ได้
3. **ข้อนี้สำคัญที่สุด: การโพสต์กลุ่มจำนวนมากจากเบราว์เซอร์ คือสิ่งที่ทำให้บัญชีโดนแบน** — เราเพิ่งคุยกันเมื่อวาน และไม่มีสคริปต์ไหนแก้ข้อนี้ได้

## 👉 ข้อเสนอ: แบ่งตามเป้าหมาย ไม่ใช่ตามเครื่องมือ

| งาน | ใช้อะไร | ใครทำ |
|---|---|---|
| **โพสต์ลงเพจ Chatudo / ILAG** | **API** (Postforme.dev หรือ Graph API ตรง) | **ผม อัตโนมัติ ไม่ใช้ winbox เลย** |
| โพสต์ในกลุ่ม FB | มือ | คุณ (ผมร่างให้) |
| ทักร้าน / DM | มือ | คุณ (ผมร่างให้) |
| **TikTok** | มือ | **คุณ — ถนัดอยู่แล้ว** |
| คอมเมนต์ตอบในเพจ | ผมร่าง คุณกด | ทั้งคู่ |

**เหตุผลที่ไม่ควรทำกลุ่มกับ DM เป็นอัตโนมัติ ไม่ใช่เพราะทำไม่ได้ — แต่เพราะการทำอัตโนมัติจะทำลายสิ่งเดียวที่ทำให้มันได้ผล คือความเป็นคนจริงของคุณ**

## ยังไม่ต้อง spawn Dev

Postforme.dev หรือ Graph API ตรง ผมต่อเองได้ ใช้เวลาไม่นาน **ค่อยพิจารณา Dev ตอนที่มีงานซ้ำ ๆ ที่ API ทำไม่ได้จริง ๆ**

# 3. Chatudo — Coding + Audit

## 🔴 ติดตั้งแต่ก้าวแรก: **โค้ดไม่ได้อยู่บนเครื่องนี้**

ผมเช็กแล้ว Contabo ไม่มี `chatudo` หรือ `lunar` — มีแต่ `mooniex-line-automation` และ `mooniex-line-poster` ซึ่งอาจเกี่ยวหรือไม่เกี่ยวก็ได้

**ต้อง clone ขึ้น Contabo ก่อน ผมถึงจะ audit ได้** (หรือบอกว่าอยู่ repo ไหน)

## สิ่งที่จะตรวจ เรียงตามที่ทำให้เจ็บที่สุดถ้าพลาด

| ลำดับ | ตรวจอะไร | ทำไมสำคัญ |
|---|---|---|
| **1** | **รองรับหลายร้านได้หรือยัง (multi-tenant)** | ถ้าตอนนี้รองรับร้านเดียว การขาย 10 ราย = เขียนใหม่ ไม่ใช่ติดตั้ง — **ข้อนี้ตัดสินทั้งไทม์ไลน์** |
| **2** | **ต้นทุนจริงต่อร้านต่อเดือน** | ถ้าค่า API ต่อร้าน ฿1,200 แล้วขาย ฿1,900 = ไม่รอด **ต้องรู้ก่อนขาย ไม่ใช่หลังขาย** |
| **3** | **ข้อมูลลูกค้าของร้าน** | แชทลูกค้าเขาอยู่ที่ไหน ใครเข้าถึงได้ เก็บนานแค่ไหน — **ร้านจะถาม และเราต้องตอบได้** |
| **4** | **ล่มแล้วรู้ไหม** | ถ้าบอทตายตอนตี 2 แล้วไม่มีใครรู้จนเช้า = ร้านเสียลูกค้าจริง |
| **5** | **API key / ความลับ** | ใครถือ ใครเปลี่ยนได้ หลุดแล้วเกิดอะไร |
| **6** | **ขั้นตอนติดตั้งที่กินเวลา** | ตัวที่จะกลายเป็นคอขวดตอนมี 10 ร้าน |

**ข้อ 1 กับ 2 ต้องรู้ก่อนทักร้านแรก** — ที่เหลือทำระหว่างทางได้

# 4. Phase 1 — 10 ร้าน ฟรี 1 เดือน

**ไอเดียถูก** แต่มีกับดักที่ทำให้พังบ่อยที่สุด

## ⚠️ ลูกค้าฟรีไม่ทำตัวเหมือนลูกค้าจ่ายเงิน

- พังก็ไม่บ่น (เกรงใจ) → **เราไม่รู้ว่าอะไรพัง ซึ่งคือเหตุผลเดียวที่เราให้ฟรี**
- ไม่ได้ใช้จริงจัง → ข้อมูลที่ได้ไม่จริง
- พอถึงวันเก็บเงิน → "ขอลองต่ออีกหน่อยนะ"

## วิธีกัน — ตกลงเป็นลายลักษณ์อักษรตั้งแต่วันแรก

```
ฟรี 1 เดือน ตั้งแต่ [วันที่ติดตั้ง] ถึง [วันที่ + 30]
เริ่มคิดเงิน ฿1,900/เดือน ตั้งแต่ [วันที่ + 31]
ถ้าไม่พอใจ บอกเลิกได้ ไม่มีผูกมัด

แลกกับ: ขออนุญาตเอาสิ่งที่เจอไปเล่าเป็นตัวอย่างได้
        (ชื่อร้านจะเปิดเผยหรือไม่ แล้วแต่พี่)
```

**"ฟรี 1 เดือน" ต้องมีวันจบที่ระบุชัด ไม่ใช่ "ฟรีไปก่อนแล้วค่อยว่ากัน"**

## และขอสิ่งนี้แทนเงิน — มีค่ากว่าเงินในเฟสนี้

ทุกสัปดาห์ถามคำถามเดียว: **"อาทิตย์นี้มันตอบอะไรผิดบ้างครับ"**

ไม่ใช่ "ใช้ดีไหม" (เขาจะตอบว่าดี ทุกคน) — **ถามหาสิ่งที่พัง เพราะนั่นคือสินค้าที่เรากำลังซื้อจากเขา**

# 6. เรื่องกฎตัดสิน "ได้รางวัล = ไปต่อ / ไม่ได้ = PARK"

**กฎชัดดี แต่ผมขอเสนอให้เพิ่มทางที่สอง**

**รางวัลคือความเห็นของคณะกรรมการกลุ่มเดียว ตัดสินครั้งเดียว** — มันเป็นสัญญาณที่ช้าและหยาบ

**สัญญาณที่เร็วกว่าและเชื่อถือได้กว่า: คนแปลกหน้าตอบสนองยังไง**

| ถ้าเจอสิ่งนี้ก่อนประกาศผล | แปลว่า |
|---|---|
| โพสต์ไหนได้ engagement สูงผิดปกติ | **มีดีมานด์จริง — ไม่ต้องรอรางวัล** |
| มีคนทักมาถามว่าทำยังไง / จ้างได้ไหม | **มีตลาดจริง** |
| โพสต์ครบ 6-12 ชิ้น แล้วเงียบสนิททุกชิ้น | **ข้อมูลพอตัดสินแล้ว — ไม่ต้องรอรางวัลเหมือนกัน** |

**ตั้งเกณฑ์สองทาง: รางวัล หรือ สัญญาณจากคนดูจริง อันไหนมาก่อนก็ใช้อันนั้น**
