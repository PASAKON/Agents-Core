## ข้อควรระวังที่เพิ่งเจอ — เมาส์ตัวเดียว

เดสก์ท็อปมีชุดเดียว **ถ้า worker กำลังคลิกอยู่แล้ว CEO เข้า VNC ไปขยับเมาส์พร้อมกัน มันชนกันจริง**
`MACHINE-LOCK.txt` คุมได้แค่ระหว่าง agent ด้วยกัน **ไม่ได้คุมคนที่เข้ามาทาง VNC**

**ก่อนเข้า VNC ให้เช็คก่อน:**
```bash
ssh -n winbox 'powershell -NoProfile -Command "Get-Content C:\mooniex\MACHINE-LOCK.txt"'
```
ถ้ามีชื่อค้างอยู่ = มี agent ทำงานอยู่ **รอ หรือบอก CTO ให้หยุดก่อน**
