## v2 — อารมณ์ (CEO 2026-09-25: "ตัวละครดูไร้อารมณ์ โทนเสียงเรียบๆ ไม่มีประจบ โกรธ โมโห ร้องไห้")

**สาเหตุในเรื่องแรก วัดจาก data file ของ banchi ACT1–7 (มีบทพูด 417 บรรทัด):**
- มีบทสั่งอารมณ์แรงแค่ **4 บรรทัด (1%)**
- คำสั่งที่ใช้บ่อยที่สุด: quiet ×25 · steady ×16 · even ×14 · flat ×13 · quieter ×11
- บล็อกเสียงประจำตัวยังมีอารมณ์ติดมาด้วย เช่น "tired man" "calm man" "who never has to raise it" ซึ่งถูกวางซ้ำทุกบรรทัด
- **สรุป: บทสั่งให้เล่นเรียบเอง** ส่วนที่ว่า Veo เล่นอารมณ์แรงได้แค่ไหนยังไม่ได้วัด

**สิ่งที่แก้ใน v2:**
1. ทุกช็อตมีบรรทัด **อารมณ์** บอก สีหน้า · น้ำเสียง · ท่าทาง ของทุกคนในเฟรม รวมถึงคนที่ไม่ได้พูด และให้ระดับความแรง 1–5
2. คำกำกับท้ายบทพูด (ภาษาอังกฤษ เพราะนี่คือคำที่จะเข้าพรอมต์) ใช้คำที่แรงและจับต้องได้ เช่น shouting · sobbing · tears streaming · voice cracking · veins on his neck · pleading, palms pressed together
3. บล็อกเสียงประจำตัวใส่ได้แค่ **เนื้อเสียง ระดับเสียง และอายุ** ห้ามมีอารมณ์หรือจังหวะพูด ถ้าเขียน "calm / tired" ไว้ในนั้นจะไปถ่วงทุกบรรทัด
4. ตอนสร้างพรอมต์ ให้ใส่อารมณ์ไว้**ต้นประโยคฉาก** ไม่ใช่เป็นคำคุณศัพท์คำเดียวท้ายบรรทัด
5. **ก่อนยิงจริง:** ทำ A/B ที่ 360p สามอารมณ์ (ตะโกนโกรธ S8 · ร้องไห้ S26 · ประจบ S11) ใช้ ~12 เครดิต ต้องได้ CEO อนุมัติก่อน
