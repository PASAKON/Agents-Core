# «น้ำไม่เลือกบ้าน» — ทะเบียนตัวละคร + State (v1, 2026-09-26)

รูปแบบเดียวกับ `taachang-CAST-STATES.md` (CEO 2026-09-25: หนึ่งตัวละครมีได้หลาย state ใช้กับ prop และ location ด้วย)
เพลตทั้งหมดมาจาก `docs/ops/briefs/ep3-plates-round1.json` (ChatGPT บน winbox) · ชื่อเพลต = ชื่อ Element ใน Flow
ช็อตไหนใช้ state ไหน กำหนดไว้ใน `ep3-ACT1..3.data.py` — ตารางนี้คือสรุปสำหรับคนอ่าน

- `<ตัว>__face` = ครึ่งตัวบน สีหน้าเฉย ฉากเทา → ตัวยึดหน้าตา
- `<ตัว>__<state>` = เต็มตัว คนเดิม ทำต่อในแชตเดียวกับ face → แนบเป็น chip ชุด (wardrobe reference)
- อารมณ์ไม่ใช่ state (เขียนในบทแต่ละช็อต) · ยกเว้นสภาพที่ติดตัวหลายช็อต เช่น เฮียกิจวันที่ 2 เหงื่อโชก หนวดขึ้น ตาบวม
- สีประจำตัว 1 สีต่อคน ไม่ซ้ำกัน: เฮียกิจ น้ำเงิน · ป้าน้อย เขียว · ยาย ม่วงอ่อน · มิ้นท์ เหลืองมัสตาร์ด · พนักงาน เขียวหัวเป็ด · เพื่อนบ้าน ส้ม

## เช็คก่อนยิง

- ทุกช็อต ≤3 คน · ไม่มีเด็ก · ไม่มีเครื่องแบบ · กลางวันทั้งหมด · ไม่มีเงินในเฟรม (`nocash`) · ไม่มีแบรนด์ (`nologo`)
- chip มากสุดต่อช็อต 8 (เพดาน Flow 10)
- ถ้าช็อตสองคนหน้าเพี้ยน: ใช้คู่ face + ชุด ตามที่วัดแล้วใน banchi · ถ้า Flow ลบคลิปที่มีเพลตใด → ย้ายตัวนั้นเป็น `TEXT_ONLY`
- QC เพลต: ดู contact sheet ด้วยตา · คนเดียวกันทุก state · ไม่มีตัวหนังสือ/โลโก้ · แก้ในแชตเดิมได้ไม่เกิน 2 ครั้งต่อเพลต
