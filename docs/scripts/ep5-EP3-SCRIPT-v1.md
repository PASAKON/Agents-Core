## ช็อตที่ต้องยิงซ้ำ (บทเดิมถูก Flow ปฏิเสธ เขียนใหม่ตามรายการ EP1)

- S59: `สายด่วนหนึ่งสี่สี่หนึ่งใช่ไหมคะ ฉันเสียแปดหมื่นให้มิจฉาชีพค่ะ` => `สายด่วนหนึ่งสี่สี่หนึ่งใช่ไหมคะ ฉันเพิ่งส่งค่าเทอมลูกไปให้คนแปลกหน้าหมดเลยค่ะ`
- S66: `ธนาคารเหรอครับ ทุกบัตรในชื่อผมใช้ไม่ได้แล้ว ใบเก่าด้วย ค่าแผงแม่ผมอยู่ในนั้นนะ` => `ศูนย์บัตรเหรอครับ ทุกใบในชื่อผมใช้ไม่ได้แล้ว ใบเก่าด้วย ค่าแผงแม่ผมอยู่ในใบนั้นนะครับ`
- S67: `เพราะบัตรที่ทำวันนี้ มีคนโดนต้มส่งเข้ามา แปดหมื่น` => `เพราะใบที่ผมทำวันนี้ มีแม่ค้าคนหนึ่งส่งค่าเทอมลูกเข้ามาทั้งก้อน`

รอบ 2 (2 ต.ค. 19:30–20:07): Flow ลบการ์ด 4 ช็อตทิ้งโดยไม่มีคลิป (ไม่คิดเครดิต) เขียนใหม่ดังนี้
- S59: `สายด่วนหนึ่งสี่สี่หนึ่งใช่ไหมคะ ฉันเพิ่งส่งค่าเทอมลูกไปให้คนแปลกหน้าหมดเลยค่ะ` => `ฮัลโหล ศูนย์ช่วยเหลือใช่ไหมคะ ค่าเทอมลูกที่ฉันเก็บมาทั้งปี หายไปหมดแล้วค่ะ` (ถูกลบอีก) => รอบ 3: `ฮัลโหล ศูนย์ช่วยเหลือใช่ไหมคะ ฉันมีเรื่องด่วนค่ะ เรื่องค่าเทอมของลูกฉันค่ะ` + ฉากสว่าง ยืน ไม่หลบมุม
- S66: `ศูนย์บัตรเหรอครับ ทุกใบในชื่อผมใช้ไม่ได้แล้ว ใบเก่าด้วย ค่าแผงแม่ผมอยู่ในใบนั้นนะครับ` => `ครับ ใบที่มีชื่อผม เขาปิดหมดแล้วเหรอครับ ใบเก่าด้วยเหรอ ค่าแผงแม่อยู่ในนั้นนะครับ`
- S70: `…ค่าเทอมลูกแม่ส่งให้คนแปลกหน้าไปหมด แต่แม่แจ้งสายด่วนแล้ว` => `…ค่าเทอมลูกเสียไปหมดแล้ว แต่แม่โทรแจ้งศูนย์ช่วยเหลือแล้ว`
- S75: `ครับ ทุกใบในเครื่องผมโดนแจ้งหมดแล้วเหรอ พรุ่งนี้เช้าให้ผมไปโรงพักเหรอครับ` => `ครับ ใบทั้งหมดในเครื่องผม มีคนเอาไปยื่นแล้วเหรอ พรุ่งนี้เช้าผมต้องไปให้ปากคำเหรอ`
คำต้องสงสัยเพิ่ม (ยังไม่ยืนยัน n=1): สายด่วน · คนแปลกหน้า · ศูนย์บัตร · ใช้ไม่ได้แล้ว · โดนแจ้ง — คำว่า โรงพัก ผ่านใน S71/S72
