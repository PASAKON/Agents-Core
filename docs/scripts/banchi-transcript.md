## หมายเหตุสำหรับคนอ่าน

- **"เดี๋ยวผมคิดให้"** (องก์ 4) คือความผิดทั้งหมดของเรื่อง ในสามคำ
- **ลุงปฏิเสธเงินวิทย์สองครั้ง** ครั้งแรกตอนร้านปกติ ครั้งที่สอง**ตอนร้านกำลังจะเจ๊งและลุงไม่มีเงินซื้อยาให้แม่** — ครั้งที่สองคือฉากที่ทำให้ตอนจบมีน้ำหนัก ถ้าไม่มีฉากนี้ ประโยค `"คนที่ให้ผมกินฟรีมาทั้งชีวิต"` เป็นแค่คำพูดลอยๆ
- **"ก็แค่ก๋วยเตี๋ยวชามเดียวลูก"** ลุงไม่เคยจดความดีของตัวเอง เหมือนที่ไม่เคยจดว่าจ่ายหนี้ไปกี่งวด — **คนนี้ไม่ทำบัญชีอะไรเลยทั้งชีวิต ทั้งขาได้และขาเสีย** นั่นคือทั้งจุดอ่อนและจุดแข็งของเขาในประโยคเดียว
- **"เอาไว้ก่อน วันหลังค่อยจ่าย"** พูดสองครั้ง — นาทีที่ 3 กับนาทีสุดท้าย บรรทัดเดียวกันเป๊ะ **ครั้งแรกคือนิสัยของพ่อ ครั้งที่สองคือเหตุผลที่ครอบครัวนี้รอด**
- **"งั้นก็ให้รอยพวกนี้พูดแทน"** ย่าที่พูดไม่ได้ กลายเป็นพยานที่เอาผิดเชิดได้จริง
- **"แล้วแกไปเอาอะไรจากคนที่ให้ผมกินฟรีมาทั้งชีวิต"** คือประโยคที่ตัดสินเชิด — ไม่ใช่กฎหมาย แต่เป็นบัญชีความดีที่เขาไปยุ่งด้วย
- **"ผมไม่ได้อยากทำแบบนี้นะพี่"** เชิดถูกทำให้ซับซ้อนวินาทีสุดท้าย แล้วถูกลงโทษอยู่ดี — แบบเดียวกับที่ฟ้ามีตาทำกับตัวร้ายทุกตอน
- **"เขาโกหกลุงตั้งแต่วันแรก"** ปิดบรรทัดที่ปลูกไว้องก์ 2 — `"ผมไม่มีเจ้านายหรอกพี่ เงินผมทั้งนั้น"`
- **"ควันน่ะ"** พ่อไทยไม่ร้องไห้ต่อหน้าลูก

## ทำไมตอนจบนี้ไม่ใช่เทวดาลงมาช่วย

| | |
|---|---|
| วิทย์โผล่มาจากไหน | **ปลูกไว้นาทีที่ 3** แล้วกลับมาอีกรอบตอนร้านเงียบ ก่อนจะเฉลยว่าเป็นตำรวจ |
| ทำไมเขาช่วย | เขากินร้านนี้ฟรีมาตั้งแต่เด็ก **ความดีของพ่อคือเหตุ ไม่ใช่โชค** |
| พ่อแจ้งความหรือเปล่า | **ไม่** พ่อปฏิเสธจะพูดถึงสองครั้ง — วิทย์ไปถามลูกแทน |
| ทำไมเพิ่งจับตอนนี้ | วิทย์ตามมาปีกว่าแล้ว **แต่ไม่มีหลักฐาน** จนกระทั่งมีคนนับไว้ |
| หลักฐานคืออะไร | แอปธนาคาร 104 + รอยขีดของย่า 104 = **208** |
| ครอบครัวได้อะไร | ย่าหายป่วย เดินได้ ทำกับข้าวเอง · ร้านมีลูกจ้าง 2 คน · ต้นมีงาน มีลูกน้อง 4 คน |
| เชิดได้อะไร | โดนจับข้อหาปล่อยกู้นอกระบบ เรียกเก็บเกินหนี้ ข่มขู่ผู้ป่วย |

**ห่วงโซ่เหตุผลไม่ขาดสักจุด:** พ่อใจดีมาทั้งชีวิต → เด็กคนนั้นโตมาเป็นตำรวจ → พ่อหยุดจ่าย → ร้านเงียบ → ตำรวจเห็นเอง → พ่อไม่ยอมพูด → ตำรวจถามลูก → ลูกมีตัวเลข → ย่ามีรอยขีด → จับได้
