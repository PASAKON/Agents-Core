# «ขายชื่อ» EP1 — ทะเบียนตัวละคร + State (v1, 2026-10-01)

รูปแบบเดียวกับ `ep4-CAST-STATES.md` · เพลตทั้งหมดมาจาก `docs/ops/briefs/ep5-plates-round1.json` (ChatGPT Plus web, ไม่เสียเครดิต) · ชื่อเพลต = ชื่อ Element ใน Flow
ช็อตไหนใช้ state ไหน กำหนดจริงใน `ep5-ACT1..3.data.py` — ตารางนี้คือสรุปสำหรับคนอ่าน

- `<ตัว>__face` = ครึ่งตัวบน สีหน้าเฉย ฉากเทา = ตัวยึดหน้าตา
- `<ตัว>__<state>` = เต็มตัว คนเดิม ทำต่อในแชตเดียวกับ face = chip ชุด
- อารมณ์ไม่ใช่ state (เขียนในบทแต่ละช็อต)
- ตัวเอก หน้าตาดี แบบบ้านๆ
- สีประจำตัว ไม่ซ้ำกัน: แม่ศรี ส้มมะละกอ · ต้น เทากับแดง · บอย ทองกับลายเสือ · ฝน เขียวมิ้นต์ · คนเก็บค่าแผง น้ำตาล · เพื่อนต้น สีทองกับคราม
