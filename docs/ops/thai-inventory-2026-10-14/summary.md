# Thai-text inventory

Generated by `tools/thai_inventory.py` (no model). Thai = characters U+0E00–U+0E7F.
**translate** = internal text that moves to English (docs, skill bodies, always-loaded prose, code comments). **keep** = CEO quotes, trigger phrases, other quoted phrases, «titles», user-facing text, runtime strings, data, test fixtures. The kind split is a lexer heuristic: it says what to read, not what to change; every diff is still read by a C-level. `est tok` = Thai × 0.85 + other ÷ 4 — an **estimate** (0.85 = Haiku 5.5 Thai rate measured 2026-10-13); measured counts for the always-loaded set are in the report.
