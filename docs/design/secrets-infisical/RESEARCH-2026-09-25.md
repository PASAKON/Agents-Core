## C. Naming conventions elsewhere

12-factor (identity in SCREAMING_SNAKE, 12factor.net/config) · AWS Secrets Manager
`<org>/<env>/<project>/…` paths for IAM prefixes (docs.aws.amazon.com prescriptive guidance) ·
Vault: pick a convention, keep paths shallow (developer.hashicorp.com/vault) · Doppler:
lowercase-hyphen projects, env slug prefix (docs.doppler.com/docs/workplace-structure) · GitHub
Actions and GitLab: A–Z, 0–9, `_` only, flags beside the name. All five keep owner, expiry and
scope out of the name.
