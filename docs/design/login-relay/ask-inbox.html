Design proposal · CTO · 23 ก.ย. 2026

Ask Inbox — ทุกขั้นที่ต้องใช้มือคุณ ทำได้จากมือถือเครื่องเดียว

ที่คุณเจออยู่สองเรื่อง คือ login หลุดทีละเครื่อง กับคำสั่ง ! ที่ต้องพิมพ์ที่เครื่องนั้นเท่านั้น จริงๆ แล้วเป็นปัญหาเดียวกัน: ขั้นตอนที่ AI ทำเองไม่ได้ ไปผูกอยู่กับหน้าจอของเครื่องนั้น ข้อเสนอนี้แยกขั้นตอนพวกนี้เป็น 3 ชนิด แล้วแก้แต่ละชนิดด้วยวิธีที่ต่างกัน

รอ CEO เคาะ 4 ข้อ (ท้ายหน้า)

คำตอบสั้น

  1. ทำให้ต้อง login น้อยครั้งลง ก่อนจะไปทำให้ login เร็วขึ้น credential ของ CLI/API ส่วนใหญ่มีแบบอายุยาวอยู่แล้ว ออกครั้งเดียวแล้วใช้ได้ทุกเครื่อง ส่วน Tailscale ทั้ง 5 เครื่องจะหมดอายุพร้อมกันช่วง ธ.ค.–ก.พ. ปิด key expiry วันนี้ใช้เวลาแค่นาทีเดียว
  2. คำสั่ง ! ของทุกเครื่องไปรวมที่ “Ask Inbox” ใน MoonieX Console (terminal.mooniex.com ที่ใช้อยู่แล้ว) ขั้นตอนคือ AI ส่งการ์ดคำขอ → มือถือแจ้งเตือน → คุณกด Run → terminal ของเครื่องปลายทางเปิดขึ้นบนมือถือ → ผลลัพธ์ส่งกลับไปให้ AI เอง
  3. login ที่ต้องทำผ่านเว็บ (Google, Flow, Higgsfield) ใช้วิธีส่งภาพหน้าจอ browser ของเครื่องนั้นมาที่มือถือ ไม่ต้องย้าย session ไปไหน โค้ดส่วนนี้มีคนเขียนไว้แล้ว 1,713 บรรทัด อยู่ใน branch ที่ยังไม่ได้ merge
  4. Termius ใช้เป็นทางสำรองได้ แต่เอามาเป็นระบบหลักไม่ได้ มันพาคุณเข้า shell ได้ก็จริง แต่ไม่รู้ว่า AI ขออะไร ผลลัพธ์ก็ไม่ส่งกลับไปให้ AI และตอนนี้ยังเข้า Mac ไม่ได้ด้วย

B Browser: ย้ายภาพหน้าจอ ไม่ย้าย session

ไอเดียที่ Park ไว้ใน LungNote คือแอป iOS เก็บ cookie แล้วส่งให้ agent ใช้ ซึ่ง CTO ตรวจแล้วว่าไม่เวิร์กด้วย 3 เหตุผล:

  • แอป iOS อ่าน session ของ Safari หรือแอปอื่นไม่ได้ เพราะ Apple sandbox กันไว้
  • session cookie ใช้ข้าม 2FA ได้ จึงเป็นความลับระดับเดียวกับรหัสผ่าน ยิ่งก๊อปไปวางหลายที่ยิ่งเสี่ยง
  • Google ผูก session ไว้กับเครื่องและ IP ถ้าย้ายไปเครื่องอื่นก็จะโดนเตะออก

ทางที่ดีกว่าคือส่งภาพหน้าจอ (relay) มือถือเปิด Console /relay (ยืนยันด้วย passkey ผ่าน Tailscale) ระบบจะคุม Chrome ของเครื่องปลายทางผ่าน CDP แล้วตั้งให้ Chrome นั้นทำตัวเป็นมือถือขนาด 390×844 Google จึงส่งหน้า login แบบมือถือมาให้ ซึ่งกดด้วยนิ้วได้สบาย ช่องพิมพ์อยู่บนมือถือคุณเอง autofill และ password manager จึงใช้ได้ตามปกติ พอพิมพ์เสร็จระบบส่งข้อความทั้งก้อนไปทีเดียว ไม่มีการเก็บอะไรไว้ และ AI ไม่เคยพิมพ์รหัสผ่านของคุณ

  • โค้ดมีอยู่แล้ว: branch agent/antigravity-login-relay commit a98f78e (20 ก.ย.) มี 14 ไฟล์ รวม test 3 ไฟล์ ยังไม่ merge และยังไม่เคยรันกับ login จริง
  • ลดจำนวนเครื่องที่ต้องถือ session: ให้แต่ละบัญชีอยู่ในโปรไฟล์เดียวบนเครื่องเดียว (“บ้านของ browser”) ส่วน automation จากเครื่องอื่นให้ต่อเข้ามาคุมผ่าน Tailscale แทนการ login ซ้ำที่เครื่องตัวเอง
  • login Google ให้เร็ว: ตั้งบัญชีให้ใช้ passkey หรือกด “ใช่ ฉันเอง” บนมือถือ จะได้แทบไม่ต้องพิมพ์รหัสเลย
  • เช็คทุกวัน: ระบบเปิดแต่ละโปรไฟล์แล้วดูว่ายัง login อยู่ไหม ถ้าหลุดจะแจ้งคุณก่อนวันถ่าย ไม่ใช่ไปรู้กลางงานถ่าย

C Ask Inbox: คำสั่ง ! ของทุกเครื่องมารวมที่เดียว

  1. 1
    AI · เครื่องไหนก็ได้
    เมื่อติดขั้นที่ต้องใช้มือคุณ AI จะเรียก ask_human(host, command, why) แทนการพิมพ์ในแชทว่า “รัน ! … ให้หน่อย”
  2. 2
    Hub · Contabo (ใน Console)
    hub เก็บการ์ดไว้ ประกอบด้วยเครื่องปลายทาง, คำสั่งแบบตรงตัว, เหตุผลภาษาไทย, สีความเสี่ยง และเวลาหมดอายุ
  3. 3
    มือถือคุณ
    มือถือแจ้งเตือนพร้อมลิงก์ เปิดการ์ดแล้วยืนยันด้วย passkey อ่านคำสั่ง แล้วกด Run บน winbox
  4. 4
    terminal จริง · เครื่องปลายทาง
    terminal ของเครื่องนั้นเปิดขึ้นบนมือถือ คุณวางโค้ด พิมพ์ key หรือรอผลได้ตามต้องการ นาฬิกา 60 วิจะเริ่มนับตอนนี้ ไม่ใช่ตอนที่ AI ขอ
  5. 5
    กลับไปหา AI
    เมื่อคำสั่งจบ exit code และผลลัพธ์ท้ายๆ จะถูกส่งกลับไปให้ AI ตัวที่ขอผ่าน mailbox แล้ว AI ก็ทำงานต่อได้เลย ถ้าเป็นการ์ด private (เช่นคำสั่งที่พิมพ์ token ออกมา) จะส่งกลับแค่ผ่านหรือไม่ผ่าน

กติกาความปลอดภัย

  • AI ส่งการ์ดได้ แต่คนกดรันได้มีแค่คุณ ไม่มีปุ่ม “อนุมัติทั้งหมด” ไม่มีการรันอัตโนมัติ และไม่มีการรันเป็นชุด
  • คำสั่งที่เห็นคือคำสั่งที่รันจริง คำสั่งถูกล็อกไว้ตั้งแต่ตอนยื่น ถ้าจะแก้ต้องยื่นการ์ดใหม่
  • เข้าได้ผ่าน Tailscale และ passkey เท่านั้นเหมือน Console ตอนนี้ ไม่มีทางเข้าจาก internet สาธารณะ
  • การ์ดหมดอายุเองใน 2 ชม. การ์ดที่ค้างนานกดรันไม่ได้
  • ความลับพิมพ์ใน terminal เท่านั้น ห้ามพิมพ์ในแชท
  • ทุกครั้งมี log ว่าใคร เมื่อไร เครื่องไหน hash ของคำสั่ง และ exit code
  • ใช้เป็นช่องหลบระบบกันพลาดของ AI ไม่ได้ การ์ดต้องบอกเป็นภาษาคนว่าคำสั่งจะเปลี่ยนอะไร ส่วนการ์ดสีแดง (ลบของ, force push, restart prod, แตะความลับ) ต้องกดยืนยันอีกชั้น
