สิ่งที่ระบบนี้จะไม่ทำ

  • ไม่เก็บ ไม่ log และไม่ส่งต่อรหัส cookie หรือค่าใน QR (ค่าใน QR ถือเป็นความลับ ถอดรหัสบนมือถือคุณเท่านั้น)
  • ไม่ใช่ remote desktop ใช้ได้กับหน้า login เท่านั้น ใช้ได้ทีละ 1 session และปิดเองเมื่อไม่ได้ใช้ 5 นาที
  • ไม่แตะ Chrome ส่วนตัวของคุณ แสดงเฉพาะ Chrome ที่เปิดไว้ให้ automation
  • AI ไม่พิมพ์รหัสผ่านแทนคุณ
  • เปิดจาก internet สาธารณะไม่ได้ ต้องผ่าน Tailscale และ passkey

ลำดับเปิดใช้

  1. Mac ก่อน: ใช้ได้ทันทีที่ merge เพราะ Chrome ที่รออยู่ (TikTok BL, Flow) อยู่บน Mac
  2. Contabo: ต้องติดตั้ง Chrome แบบไม่มีหน้าจอก่อน
  3. winbox: ต่อผ่าน Contabo ด้วย ssh และต้องไม่รบกวนจอของบอท Cookie Run

ปรับตามที่คุณสั่ง (23 ก.ย.) และค่าที่ผมเลือกให้

  • ตัดขั้นเลือกวิธีออก ระบบเลือก QR หรือฟอร์มเอง และเปลี่ยนให้เองถ้าหน้าเว็บเปลี่ยนกลางทาง
  • รอผลอัตโนมัติ login เสร็จแล้วระบบไปหน้ารอผลเอง ไม่มีปุ่ม “เสร็จแล้ว”
  • ถ้า error มี Error ID ให้ copy ผมใช้ ID นั้นเปิดบันทึกบนเครื่องได้ทันที บันทึกเก็บแค่ว่าพังขั้นไหนและหน้าเว็บขึ้นว่าอะไร ไม่เก็บสิ่งที่พิมพ์ ค่าใน QR หรือ cookie
