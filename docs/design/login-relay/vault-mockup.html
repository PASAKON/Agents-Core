รายการนี้แสดงอีเมลแบบบังบางส่วนเท่านั้น รหัสผ่านถอดได้บนมือถือคุณหลัง Face ID เท่านั้น ลบแล้วหายจาก server ทันที

Face ID

จำลองเท่านั้น ไม่มีการเก็บอะไร ตัวอย่างอีเมลเป็นข้อมูลสมมติ

รหัสเก็บที่ไหน และใครอ่านได้

iPhone ของคุณ

ถือกุญแจ passkey ที่ใช้ login Console อยู่แล้ว ทุกครั้งที่ Face ID ผ่าน passkey จะสร้างกุญแจลับออกมา แล้วมือถือใช้กุญแจนั้นเข้ารหัสหรือถอดรหัสบัญชี

อ่านรหัสได้: ใช่ เฉพาะหลัง Face ID

Relay (Contabo)

เก็บเฉพาะก้อนข้อมูลที่ล็อกแล้ว ชื่อเว็บ และอีเมลแบบบังบางส่วนไว้โชว์ในรายการ ไม่มีกุญแจ ไม่มีรหัสจริง

อ่านรหัสได้: ไม่ได้ ทั้งตัว server, AI และใครที่เข้าถึงเครื่อง

เครื่องปลายทาง

ได้รับรหัสเฉพาะตอนกรอกลงหน้า login ผ่านท่อเดียวกับที่คุณพิมพ์อยู่ตอนนี้ ไม่มีการบันทึก log

อ่านรหัสได้: แค่ตอนกรอก เหมือนตอนคุณพิมพ์เอง

  • ทำงานแบบเดียวกับตัวจัดการรหัสผ่านที่ใช้ passkey ปลดล็อก (เช่น 1Password หรือ Bitwarden) ต่างกันตรงที่อยู่ใน relay ของเราเอง
  • ใช้ได้กับทุกเครื่อง เพราะบัญชีผูกกับชื่อเว็บ (google.com) ไม่ได้ผูกกับเครื่อง
  • ความเสี่ยงที่เหลือ: คนที่ได้มือถือคุณพร้อมผ่าน Face ID ได้ ซึ่งเท่ากับ Apple Passwords

ทางเลือกที่ดูมาแล้ว

ทางได้เสีย
A. คลังรหัสใน relay + Face ID (แนะนำ)ตรงกับที่คุณขอทุกข้อ: เลือกบัญชีต่อเว็บ กรอก 2 ขั้นให้เอง ใช้ได้ทุกเครื่อง server อ่านรหัสไม่ได้ต้องสร้างใหม่ (งาน DEV 1–2 ชิ้น) และต้องพิสูจน์ก่อนว่า iPhone รองรับ
B. Apple Passwords ใน iPhoneมีอยู่แล้ววันนี้: ก๊อปรหัสจาก Passwords (Face ID) มาวางในช่องของ relayต้องก๊อปวางเองทีละช่อง และ iPhone มองว่าทุกเว็บเป็น terminal.mooniex.com เลยเสนอให้อัตโนมัติไม่ตรงเว็บ
C. ให้ Chrome แต่ละเครื่องจำเองไม่ต้องสร้างอะไรต้องจำแยกทุกเครื่อง และป๊อปอัป “บันทึกรหัส” ของ Chrome ไม่โผล่ในภาพที่ส่งมามือถือ

ต้องพิสูจน์ก่อนสร้างจริง

  • iPhone ต้องรองรับการสร้างกุญแจจาก passkey (WebAuthn PRF ซึ่ง iOS 18 ขึ้นไปควรรองรับ) ขั้นแรกจะทำหน้าทดสอบเล็กๆ ให้คุณกดครั้งเดียวบนมือถือจริง ถ้าไม่รองรับ ผมจะกลับมาถามคุณ ไม่แอบเปลี่ยนไปใช้วิธีที่ปลอดภัยน้อยกว่า
  • Google อาจถามยืนยันเพิ่มเมื่อ login จากเครื่องที่ไม่คุ้น ซึ่งเป็นเรื่องปกติ ขั้นนั้นคุณทำเอง
  • งานนี้เริ่มได้หลังงานแก้ relay ที่รันอยู่ (task-2a8a9200) merge เพราะแก้ไฟล์ชุดเดียวกัน

ขอคำตอบ 2 ข้อ

  1. ต้อง Face ID ทุกครั้งที่กรอก (แนะนำ เหมือน Apple Passwords) หรือครั้งเดียวต่อ 5 นาที (สะดวกกว่าถ้าจะ login หลายเครื่องติดกัน)
  2. บัญชีที่จำไว้ใช้ได้ทุกเครื่องไหม (แนะนำ) หรือแยกเก็บต่อเครื่อง
