# บรีฟสำหรับ GPT-6 Astra — วางลุคเกรดสี «Sorry, Sir»

CTO 2026-09-11 · ใช้คู่กับ `absence-grading-plan-20260911.md`
**นี่คือสิ่งที่จะส่งให้ Astra ใน session เดียว แล้วปิด**

---

## ทำไมบรีฟนี้สั้นกว่าที่คิด

**เราไม่ต้องให้ Astra คิดลุคใหม่** — หนังเรื่องนี้มีสเปกสีเขียนไว้แล้ว และเขียนซ้ำเหมือนกันเป๊ะใน
**77 ใบ prompt** คือทุกคลิปถูก generate มาโดยเล็งลุคนี้อยู่แล้ว

> *"Colour grade — warm shadow, cold white: amber-orange highlights and mids, whites pushed
> slightly cool, shadows deep red-brown, halation around every lamp. Photographed, not rendered:
> fine film grain, faint gate weave, slight colour fringing."*

**งานของ Astra จึงไม่ใช่ "ออกแบบลุค" แต่คือ "ทำให้ทุกคลิปตรงกับลุคที่เขียนไว้แล้ว"**
นั่นเป็นคำถามที่แคบกว่ามาก ตอบได้ใน session เดียว และตรวจได้ว่าถูกหรือผิด

---

## ⚠️ ข้อที่ต้องบอก Astra ให้ชัด ไม่งั้นมันจะทำพัง

**ฟุตเทจของเราไม่ใช่ LOG** เดโมที่ Astra ทำกับ Higgsfield เป็น *"flat Apple Log 2 footage"* ซึ่ง
เริ่มจากภาพแบน ๆ ไร้สี — **ของเราตรงข้าม** เป็น .MP4 720p ที่โมเดลใส่ลุคมาให้แล้วระดับหนึ่ง

ถ้ามันเผลอใส่ LOG-to-Rec709 transform เข้าไป **ภาพจะพังทันที** ต้องเขียนกำกับว่า:
*"This is NOT log footage. It is already-graded Rec.709 output. Do not apply any log conversion,
input transform or colour space transform."*

**งานคือแก้และทำให้เท่ากัน ไม่ใช่เกรดจากศูนย์**

## เฟรมที่จะส่งไป — เลือกให้ครอบคลุมปัญหาจริง

ไม่ใช่ส่งเฟรมสวย ๆ แต่ส่งเฟรมที่**กินขอบเขตของปัญหา**

| คลิป | ส่งไปทำไม |
|---|---|
| **S22 ลังไม้** | **ตัวปัญหาที่รู้อยู่แล้ว** — วัดได้ว่าผนัง R−B = +6 คือกลาง ไม่ใช่อำพัน |
| **S2AC take 4** | ฉากกำแพง ผนังขาวเต็มเฟรม — ตัวชี้ว่า "whites pushed slightly cool" มาไหม |
| **S2PT take 4** | ช็อตเคลื่อนกล้อง มีเสาโครเมียมกับไฟส้ม — ตัวชี้ halation |
| **S21 กำแพงทีวี** | **ยิงด้วย 2.0 Fast ไม่ใช่ 2.5** — สีจัดกว่าเพื่อน ตัวชี้ว่าจะดึงให้เข้าพวกยังไง |
| **S17b ฉากปิด** | มืดกว่าเพื่อน โพรงกำแพงดำ — ตัวชี้เงา "deep red-brown" |

**S21 สำคัญที่สุดในชุดนี้** เพราะมันมาจากคนละโมเดล ถ้าลุคเดียวแก้ทั้ง 2.5 และ 2.0 Fast ได้
แปลว่าใช้ได้ทั้งเรื่อง ถ้าไม่ได้ ก็รู้ตั้งแต่ต้นว่าต้องมีสองลุค

## สัญญาผลลัพธ์ — ข้อนี้สำคัญที่สุดในเอกสาร

**ห้าม Astra ตอบเป็นร้อยแก้ว** คำตอบแบบ *"ดันให้อุ่นขึ้นและเพิ่มคอนทราสต์"* เอาไปทำอะไรไม่ได้เลย
worker ต้องพิมพ์ค่าลง Resolve ได้ทันทีโดยไม่ต้องตีความ

**ต้องขอกลับมาเป็น:**

1. **node ทีละตัว เรียงลำดับ** — node 1, node 2, … พร้อมบอกว่าแต่ละ node ใช้เครื่องมืออะไร
   (Color Wheels / Curves / Color Warper / HSL Qualifier)
2. **ค่าตัวเลขจริงทุกพารามิเตอร์** — Lift/Gamma/Gain แยก R,G,B · Temperature · Tint · Contrast ·
   Pivot · Saturation · จุดบนเส้น curve เป็นพิกัด
3. **หนึ่งบรรทัดต่อ node ว่าทำไม** — ไม่ใช่เพื่อความสวยงาม แต่เพื่อให้**ผมตรวจตรรกะได้** ไม่ใช่แค่
   ตัวเลข ถ้าเหตุผลผิด ตัวเลขก็ผิด
4. **ระบุว่า node ไหนคือ "ลุคหลัก"** ที่จะเซฟเป็น LUT แปะทั้งเรื่อง และ node ไหนคือ**ส่วนแก้รายคลิป**
   — การแยกสองอย่างนี้คือสิ่งที่ทำให้งานถูก ถ้าทุก node เป็นรายคลิป เราต้องทำ 40 รอบ

**ถ้าตอบมาไม่ครบ 4 ข้อนี้ = ส่งกลับไปถามใหม่ ไม่ใช่เดาเอง**

## ข้อห้าม

- **ห้ามใช้ฟีเจอร์ที่สร้างพิกเซลใหม่** — generative fill, AI upscale, detail synthesis
  (รุ่นฟรีไม่มีอยู่แล้ว แต่เขียนกันไว้)
- **ห้ามใส่ log/colour-space transform** ตามเหตุผลข้างบน
- **ห้ามเปลี่ยนเฟรมมิ่ง crop zoom หรือความเร็ว** — นี่คืองานสี ไม่ใช่งานตัด
- **ห้ามใส่ film grain เพิ่ม** — คลิปมี grain มาจากการ generate แล้ว ใส่ซ้ำจะเละ

## เกณฑ์ตรวจของผม

ตรวจ**ด้วยตา** ตามที่ CEO สั่ง ไม่ใช่ด้วยตัวเลข — ตัวเลขใช้ยืนยันสิ่งที่ตาเห็นแล้วเท่านั้น

1. ผนังขาวอ่านเป็น**ขาวอมเย็น** ไม่ใช่ขาวกลางและไม่ใช่ขาวอมเหลือง
2. เงาอ่านเป็น**น้ำตาลแดงลึก** ไม่ใช่เทาและไม่ใช่ดำสนิท
3. ไฟโคฟกับโคมมี **halation** ฟุ้งนุ่มรอบดวง
4. **S21 (2.0 Fast) กับ S2AC (2.5) วางติดกันแล้วดูเป็นหนังเรื่องเดียวกัน** — ข้อนี้คือข้อชี้ขาด
5. สีผิวคนยังเป็นผิวคน ไม่เขียวไม่ส้มเกิน

**ถ้าข้อ 4 ไม่ผ่าน ลุคเดียวใช้ไม่ได้ทั้งเรื่อง** ต้องแยกเป็นสองลุคแล้วบอกห้องตัดให้ชัดว่าคลิปไหนใช้อันไหน
