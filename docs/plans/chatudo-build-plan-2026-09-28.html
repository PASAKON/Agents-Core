แนะนำ: ใช้โค้ด ClaudeFlow ชุดเดิม แต่รันเป็นระบบที่ 2 แยกต่างหาก คือ container ของ Chatudo ต่อกับ Supabase ของ Chatudo ที่เปิดไว้แล้ว (gcjdirrtvybhvghjtscf, บัญชี pass.gob2) และใช้โดเมน api.chatudo.com เริ่มตั้งแต่ร้านนอกร้านแรก วิธีนี้ยังใช้ repo เดียวตามกฎ 31 ก.ค. และถ้า MoonieX โดนตรวจเรื่อง forex ข้อมูลของร้านลูกค้าจะไม่ได้อยู่ในฐานข้อมูลเดียวกัน ค่าใช้จ่ายช่วงแรก $0 เพราะ Supabase แพ็กฟรีพอใช้ (ประมาณการ)

CEO ตัดสิน: แยกระบบ Chatudo ไปใช้ Supabase ของ Chatudo โดยโค้ดยังอยู่ repo เดิม

อีกทาง: ใช้ฐานข้อมูล MoonieX ต่อไปจนกว่าจะแยก repo ตอน มิ.ย. 2028 วิธีนี้เร็วกว่าประมาณ 3 วันทำงาน แต่ข้อมูลร้านจะอยู่ปนกับข้อมูล forex ประมาณ 20 เดือน

  2. Meta รีวิวไม่ผ่านหรือช้า ถ้าเป็นแบบนั้น แพ็ก Pro เดือน ม.ค. อาจมีแค่ LINE ทางเลี่ยงคือเพิ่มเจ้าของเพจเป็นผู้ทดสอบของแอปเรา ซึ่งใช้ได้กับร้านจำนวนน้อยเท่านั้น และยังไม่ได้ยืนยัน
  3. SendPulse ไม่ต่ออายุ เมื่อหมดอายุ FB/IG ของ MoonieX เองจะหยุดทำงาน เรื่องนี้เป็นงานคนละส่วนกับ Chatudo แต่โค้ด Messenger ทางตรงที่ทำในงาน C1 นำไปใช้แก้ได้
  1. ข้อความที่แอดมินอนุมัติจะส่งแบบ push และใช้โควตา LINE OA ของร้าน ร้านที่ใช้แพ็กฟรีอาจใช้โควตาหมดเร็ว ราคาแพ็ก LINE OA ไทยตอนนี้ยังไม่ได้เช็ก งาน N2 จะวัดจำนวนจริงแล้วส่งให้ CMO

  3. ตัวเลขของ CMO มาจากแบบจำลองทั้งหมด งานตั้งแต่ G3 ไปจะเริ่มเมื่อผ่านประตูแล้วเท่านั้น
