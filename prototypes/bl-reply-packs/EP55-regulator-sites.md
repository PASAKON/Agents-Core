# เว็บหน่วยงานกำกับ เช็กใบอนุญาตโบรกเกอร์ได้จริง

เนื้อหาเพื่อการศึกษา ไม่ใช่คำแนะนำหรือการชักชวนลงทุน — ไม่แนะนำหรือจัดอันดับโบรกเกอร์
เจ้าไหนทั้งสิ้น ทุกลิงก์ด้านล่างคือเว็บไซต์ทางการของหน่วยงานกำกับดูแลเอง เปิดและ
ยืนยันแล้วว่าเข้าถึงได้จริงเมื่อวันที่ 23 กันยายน 2569

## ทำไมต้องเช็กเอง

ชื่อดัง โลโก้บนหน้าเว็บ หรือยอดผู้ใช้เยอะ ไม่ได้แปลว่ามีใบอนุญาตจริง ใบอนุญาต
แต่ละหน่วยงานตรวจคนละเรื่องกัน และบางเกาะเล็กออกใบอนุญาตให้ง่ายมากแลกกับ
ค่าธรรมเนียมรายปี — วิธีเดียวที่เชื่อถือได้คือค้นเลขใบอนุญาตเองจากเว็บหน่วยงาน
โดยตรง ไม่ใช่เชื่อคำโฆษณา

## รายชื่อเว็บหน่วยงานกำกับ (เช็กแล้ว 23 ก.ย. 2569)

1. **ก.ล.ต. ไทย (SEC Thailand) — SEC Check First**
   https://market.sec.or.th/LicenseCheck/Search
   ค้นชื่อบริษัทหรือชื่อผลิตภัณฑ์ที่ได้รับอนุญาตให้ประกอบธุรกิจในตลาดทุนไทย

2. **UK FCA — Financial Services Register**
   https://register.fca.org.uk/s/
   ค้นชื่อหรือหมายเลขอ้างอิง (Firm Reference Number) ของบริษัทที่ได้รับอนุญาต
   จากสหราชอาณาจักร

3. **ASIC (ออสเตรเลีย) — Professional Registers Search**
   https://service.asic.gov.au/search/
   ตรวจสอบว่าบุคคลหรือองค์กรได้รับใบอนุญาตให้บริการทางการเงินในออสเตรเลียหรือไม่

4. **CySEC (ไซปรัส) — Investment Firms Register**
   https://www.cysec.gov.cy/en-GB/entities/investment-firms/cypriot/
   รายชื่อบริษัทหลักทรัพย์ที่ได้รับอนุญาต (CIF) ภายใต้การกำกับของไซปรัส

5. **US NFA — BASIC**
   https://www.nfa.futures.org/BasicNet/
   ค้นสถานะการจดทะเบียนของบริษัทและบุคคลในอุตสาหกรรมอนุพันธ์ของสหรัฐฯ

6. **MAS (สิงคโปร์) — Financial Institutions Directory**
   https://eservices.mas.gov.sg/fid
   ค้นสถาบันการเงินที่ได้รับใบอนุญาตจากธนาคารกลางสิงคโปร์

7. **Japan FSA — List of Licensed (Registered) Financial Institutions**
   https://www.fsa.go.jp/en/regulated/licensed/index.html
   รายชื่อสถาบันการเงินที่ได้รับใบอนุญาตจากหน่วยงานกำกับของญี่ปุ่น (บางรายการ
   เป็นไฟล์ PDF/Excel ภาษาญี่ปุ่น)

## วิธีใช้

1. หาว่าโบรกที่จะฝากเงินอ้างว่ามีใบอนุญาตจากหน่วยงานไหน
2. เข้าเว็บหน่วยงานนั้นตรงจากลิงก์ด้านบน แล้วค้นชื่อบริษัทหรือเลขใบอนุญาตเอง
3. ถ้าค้นไม่เจอ หรือชื่อ/เลขไม่ตรงกับที่โบรกอ้าง ให้ระวังไว้ก่อนฝากเงินก้อนใหญ่
4. จดทะเบียนที่เกาะเล็กที่ไม่มีใครกำกับจริง หรือใบอนุญาตตรวจแค่การจดทะเบียนบริษัท
   ไม่ได้ตรวจความปลอดภัยของเงินลูกค้า — ให้ระวังไว้เช่นกัน แม้ค้นเจอชื่อ
