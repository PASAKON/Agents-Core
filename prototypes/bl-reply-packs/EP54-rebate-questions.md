# คำถามที่ควรถามโบรกเกอร์ เรื่อง Rebate

เนื้อหาเพื่อการศึกษา ไม่ใช่คำแนะนำหรือการชักชวนลงทุน — ไม่แนะนำหรือจัดอันดับโบรกเกอร์
เจ้าไหนทั้งสิ้น ใช้ถามโบรกที่คุณมีบัญชีอยู่แล้วเพื่อตรวจสอบสิทธิ์ของตัวเอง

## ทำไมต้องถาม

ทุกครั้งที่มีการส่งออเดอร์ โบรกเกอร์มีเงินก้อนหนึ่งที่ถูกจัดสรรไว้เป็นส่วนหนึ่งของ
สเปรดหรือค่าคอมมิชชั่นอยู่แล้ว เงินก้อนนี้จะถูกจ่ายคืนให้คนที่แนะนำคุณเข้ามา (IB)
หรือถ้าไม่มีใครแนะนำ โบรกก็เก็บไว้เองทั้งหมด — ไม่ได้แปลว่าคุณจ่ายถูกลง เพียงแต่
ไม่มีใครมารับส่วนแบ่งแทนคุณ คำถามด้านล่างช่วยให้คุณรู้ว่าเงินก้อนนี้ไปอยู่กับใคร

## รายการคำถาม

1. **บัญชีของฉันตอนนี้ผูกอยู่กับ IB คนไหนหรือเปล่า** — เช็กได้จากหน้าบัญชีหรือ
   ถามฝ่ายบริการลูกค้าโดยตรง
2. **โบรกมีโปรแกรม Rebate ให้ลูกค้าทั่วไปไหม หรือมีให้เฉพาะคนที่สมัครผ่าน IB**
3. **อัตรา Rebate ต่อ Lot ของสินค้าที่ฉันเทรดคือเท่าไหร่** — ถามเป็นตัวเลขจริง
   ไม่ใช่คำตอบกว้างๆ
4. **ถ้าฉันไม่ได้สมัครผ่าน IB คนไหน เงินก้อนนี้ยังถูกจ่ายออกจากทุกออเดอร์อยู่ไหม
   แล้วใครเป็นคนได้**
5. **Rebate จ่ายบ่อยแค่ไหน และเช็กยอดสะสมได้จากที่ไหน** — รายวัน รายสัปดาห์
   หรือต้องขอเอง
6. **ถ้าอยากเปลี่ยน IB หรือยกเลิกการผูกบัญชีกับ IB เดิม ทำได้ไหมและทำอย่างไร**
7. **สเปรดหรือค่าคอมมิชชั่นที่ฉันจ่ายอยู่ตอนนี้ เปลี่ยนแปลงไหมถ้าฉันมีหรือไม่มี IB**
   — ควรเท่ากันเสมอ ถ้าคำตอบไม่ตรงนี้ควรถามต่อ
8. **ยิ่งเทรดถี่หรือใช้ล็อตใหญ่ขึ้น เงินก้อนนี้โตขึ้นตามสัดส่วนอย่างไร**

## วิธีใช้คำถามนี้

ถามตรงกับฝ่ายบริการลูกค้าของโบรกที่คุณมีบัญชีอยู่แล้ว ขอคำตอบเป็นตัวเลขและ
เงื่อนไขที่เขียนไว้เป็นลายลักษณ์อักษร ไม่ใช่แค่คำอธิบายปากเปล่า ถ้าโบรกตอบ
ไม่ชัดหรือหลีกเลี่ยงคำถามใดคำถามหนึ่ง นั่นคือสัญญาณที่ควรถามต่อให้ละเอียดขึ้น
