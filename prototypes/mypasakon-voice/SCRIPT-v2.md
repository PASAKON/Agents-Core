## บทพูด

นี่คือ AI ที่ผมใช้เทรดจริงมาตลอดแปดเดือนนะครับ
นั่นก็คือ Claude Code ครับ

ผมลองมาหมดแล้วนะครับ ทั้ง ChatGPT ทั้ง Gemini ทั้ง Grok
บอทเทรด AI Agent อะไรที่เขาว่าดีๆ ผมลองมาหมดแล้วจริงๆ
แต่ผมบอกตรงๆ เลยนะครับ ว่าไม่มีตัวไหนถูกใจผมเท่าตัวนี้เลย
และผมก็ใช้มันอยู่ทุกวันจนถึงวันนี้

แล้วผมเอามันมาทำอะไรครับ
ผมเอามันมาเป็นผู้ช่วยวิเคราะห์การเทรดของผมนะครับ
แต่ไม่ใช่แค่นั้นครับ มันเทรดให้ผมได้ด้วย
มันทำสถิติให้ คำนวณความเสี่ยงให้
แล้วก็ย้อนไปทดสอบกับข้อมูลเก่าให้ผมได้หมดเลยนะครับ

แต่สิ่งที่ผมชอบที่สุดเลยนะครับเพื่อนๆ
ก็คือมันไม่หลับไม่นอนนะครับ

เมื่อคืนนี้นะครับ ก่อนผมจะเข้านอน
ผมสั่งมันไปแค่ประโยคเดียวเองครับ
ผมบอกว่า ไปวิจัยกลยุทธ์การเทรดทุกตัวย้อนหลังห้าปีมาให้ผมที

แล้วผมก็ไปนอนนะครับ

พอตื่นเช้ามา เพื่อนๆ รู้ไหมครับว่าผมเจออะไร
มันนั่งไล่กราฟย้อนหลังให้ผมทั้งคืนเลยครับ
มันไล่ทดสอบให้ผมเป็นหมื่นๆ รอบเลยนะครับ
แล้วสรุปมาให้ผมเป็นตารางเรียบร้อย
ว่ากลยุทธ์ไหนอยู่รอด กลยุทธ์ไหนพัง

แล้วมันไม่ได้บอกแค่ว่าตัวไหนดีนะครับ
มันบอกผมด้วยว่าทำไมมันถึงดี
มันบอกว่าตัวที่ชนะเนี่ย ชนะเพราะอะไร
แล้วมันจะพังตอนไหน

งานแบบนี้นะครับ ถ้าผมนั่งทำเองคนเดียว
ผมว่าเป็นเดือนก็ยังไม่เสร็จนะครับ
แต่มันทำให้เสร็จในคืนเดียว ตอนที่ผมนอนหลับอยู่

เพราะฉะนั้นนะครับ ผมเลยตัดสินใจแล้วครับ
ว่าต่อจากนี้ช่องนี้จะไม่ได้มีแค่เรื่องเทรดอย่างเดียว
ผมจะสอนเพื่อนๆ ใช้ AI มาเป็นผู้ช่วยตัวเองด้วยนะครับ
ตั้งแต่ติดตั้ง ตั้งแต่สั่งงานมันครั้งแรก ไปจนถึงใช้มันจริงกับพอร์ตตัวเอง

เพื่อนๆ คนไหนอยากลองของแบบนี้บ้าง
คอมเมนต์คำว่า Claude ไว้ได้เลยครับ
เดี๋ยวผมทำคลิปสอนติดตั้งให้ดูกันแบบเต็มๆ เลยนะครับ
