## บทพูด

นี่คือ AI ที่ผมใช้เทรดจริงมาตลอดแปดเดือน นั่นก็คือ Claude Code นี่แหละนะครับ

ลองมาหมดแล้ว ทั้ง ChatGPT ทั้ง Gemini ทั้ง Grok แล้วก็บอทเทรด AI Agent อะไรที่เขาว่าดีๆ เนี่ย ลองมาหมดแล้วจริงๆ แต่บอกตรงๆ ว่าไม่มีตัวไหนถูกใจเลยสักตัวเท่าตัวนี้จริงๆ แล้วก็ใช้มันอยู่ทุกวันจนถึงวันนี้นะครับ

แล้วเอามันมาทำอะไรนะครับ ผมเอามันมาเป็นผู้ช่วยวิเคราะห์การเทรดของผม แต่ไม่ใช่แค่นั้น มันเทรดให้ผมได้ด้วย ทำสถิติให้ก็ได้ คำนวณความเสี่ยงให้ก็ได้ แล้วก็ย้อนไปทดสอบกับข้อมูลเก่าให้ได้หมดเลย แต่สิ่งที่ชอบที่สุดเลยก็คือมันไม่หลับไม่นอนนะครับ

เมื่อคืนนี้ ก่อนเข้านอน สั่งมันไปแค่ประโยคเดียวเอง บอกว่าไปวิจัยกลยุทธ์การเทรดทุกตัวย้อนหลังห้าปีมาให้หน่อย แล้วก็ไปนอนนะครับ

พอตื่นเช้ามา เพื่อนๆ รู้ไหมครับว่าเจออะไร มันก็นั่งไล่ดูกราฟย้อนหลังให้ทั้งคืนเลย ไล่ทดสอบให้เป็นหมื่นๆ รอบ แล้วสรุปออกมาเป็นตารางเรียบร้อยเลยว่ากลยุทธ์ไหนอยู่รอด กลยุทธ์ไหนพังไปนะครับ

แล้วมันไม่ได้บอกแค่ว่าตัวไหนดีนะครับ มันบอกด้วยว่าทำไมถึงดี ตัวที่ชนะเนี่ย ชนะเพราะอะไร แล้วจะพังตอนไหนนะครับ

งานแบบนี้เนี่ย ถ้าผมนั่งทำเองคนเดียว ผมว่าเป็นเดือนก็ยังไม่เสร็จ แต่มันทำให้เสร็จได้ในคืนเดียว ตอนที่ผมกำลังนอนหลับอยู่นะครับ

เพราะฉะนั้นแล้วตัดสินใจแล้ว ว่าต่อจากนี้ช่องนี้จะไม่ได้มีแค่เรื่องเทรดอย่างเดียวอีกต่อไปแล้ว จะสอนใช้ AI มาเป็นผู้ช่วยตัวเองด้วย ตั้งแต่วิธีติดตั้ง ตั้งแต่สั่งงานครั้งแรก ไปจนถึงเอาไปใช้จริงกับพอร์ตตัวเองนะครับ

ใครที่อยากลองของแบบนี้บ้าง คอมเมนต์คำว่า Claude ไว้ใต้คลิปได้นะครับ เดี๋ยวผมทำคลิปสอนวิธีติดตั้งให้คุณดูกันแบบเต็มๆ ทีละขั้นตอนเลยนะครับ
