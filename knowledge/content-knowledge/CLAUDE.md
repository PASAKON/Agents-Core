# `content-knowledge/` — content_strategist knowledge bank

Use this when producing copy, scripts, articles, threads, newsletters,
or any text artifact carrying a brand voice. Shape mirrors
`mooniex-claudesign/`.

## Read order (workers MUST follow on every task)

1. **`craft/`** — universal don'ts (em-dash ban, AI tropes, hook discipline).
2. **`voices/<brand>/VOICE.md`** — brand voice doc (tone, banned words,
   sentence rhythm, signature moves). If missing, ask CMO to create.
3. **`skills/<format>/SKILL.md`** — artifact shape (e.g., `thread-x`,
   `linkedin-essay`, `newsletter-edition`, `tiktok-script`,
   `landing-hero-copy`).

## How CMO/CTO use this bank

- CMO writes/owns `voices/<brand>/VOICE.md` per brand.
- CTO reads voices for site copy on landing pages (still routes the work
  to content_strategist via task, but uses VOICE.md to vet briefs).

## Hard rules

1. **Em-dash ban** in any generated copy. Use period or middle-dot.
2. **No AI tropes**: "unlock", "elevate", "delve", "in today's
   fast-paced world", "harness the power of", "tapestry of...".
3. **Voice is final.** If VOICE.md says no exclamation marks, no
   exclamation marks even if "the brief feels excited."
4. **One brand per artifact.** No mixing voices unless the task is
   explicitly cross-brand.
