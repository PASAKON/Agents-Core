## Quality note — read before using

These are **auto-generated captions**, not a professional transcript:
- ~90% readable, but proper nouns/names routinely mangle (e.g. "Edward
  Beggett" → "เอ็ดเวิร์ด biggest", "London" → "tottenham", brand name
  "youaretrader.com" → "you have ดอทคอม")
- Numbers and $/currency figures are usually accurate — spot-check any
  you plan to reuse in a script (don't trust blindly)
- Treat as **plot/structure reference** (hook style, pacing, how the
  story turns), not a citable transcript

## How to use this for a script brief

1. Read `content-knowledge/craft/` + relevant `voices/<brand>/VOICE.md` first (org rule, see `content-knowledge/CLAUDE.md`) — voice/tone always overrides the source narrator's style.
2. Pick 1-2 transcripts matching the story shape you need (underdog/rags-to-riches, cautionary-loss, veteran-trader-psychology, etc).
3. Extract the **beat structure** (hook → setup → struggle → turn → result → lesson), not sentences.
4. Verify any hard numbers independently before they go in a MoonieX script.
